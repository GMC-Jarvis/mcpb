# 카드뉴스 스튜디오

인스타그램 카드뉴스 채널 5종(정보 / 사회 / 연예 / 경제 / 이슈)을 위한 카드뉴스 제작 웹앱입니다.
백엔드 없이 브라우저(로컬스토리지)만으로 동작하는 정적 웹페이지라 별도 설치 없이 바로 사용할 수 있습니다.

## 실행 방법

```bash
cd card-news-app
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

또는 `index.html` 파일을 브라우저로 직접 열어도 됩니다.

## 주요 기능

- **채널 5개**: 1.정보카드뉴스 2.사회카드뉴스 3.연예카드뉴스 4.경제카드뉴스 5.이슈카드뉴스
- **채널 프로필 변경**: 1번 채널부터 순서대로 프로필 사진, 채널명, 아이디, 소개글을 바꿀 수 있습니다. 변경사항은 브라우저에 자동 저장됩니다.
- **바이럴 문구 추천**: 카테고리별로 미리 작성된 후킹형 카드뉴스 문구 세트를 한 번의 클릭으로 전체 슬라이드에 채워 넣을 수 있습니다 (`js/content.js`의 `VIRAL_SETS`에서 문구를 추가/수정 가능).
- **슬라이드(카드) 편집**: 슬라이드 추가/복제/삭제, 배경(채널 색상 그라데이션 또는 직접 업로드한 사진), 헤드라인/본문 텍스트 편집.
- **인스타그램 규격 미리보기 & 다운로드**: 1080×1350(4:5) 캔버스로 실시간 미리보기, PNG로 낱장 또는 전체 슬라이드 일괄 다운로드.

## 폴더 구조

```
card-news-app/
├── index.html      # 레이아웃 (채널 탭 / 프로필 패널 / 에디터 / 미리보기)
├── css/style.css    # 다크 테마 스타일
├── js/content.js    # 채널 기본 프로필 + 카테고리별 바이럴 문구 세트
└── js/app.js        # 상태 관리, 캔버스 렌더링, 다운로드 로직
```

## 문구 세트 추가하기

`js/content.js`의 `VIRAL_SETS` 객체에 카테고리 키(`info`, `society`, `entertainment`, `economy`, `issue`)별로
`{ title, slides: [{ title, body }, ...] }` 형태로 항목을 추가하면 에디터의 "바이럴 문구 세트 불러오기" 목록에 자동으로 표시됩니다.
